# Online Store

Учебный проект интернет-магазина, создаваемый в рамках курса по Django.

## Описание
Проект разрабатывается поэтапно. На текущем этапе:
- Настроена базовая структура Django-проекта
- Создано приложение `catalog` для каталога товаров
- Реализованы главные страницы (Home и Contacts) с использованием Bootstrap
- Добавлена форма обратной связи с обработкой данных

## Установка и запуск
1. Клонируйте репозиторий
2. Создайте виртуальное окружение: `python -m venv venv`
3. Активируйте его: `venv\Scripts\activate`
4. Установите зависимости: `pip install django`
5. Примените миграции: `python manage.py migrate`
6. Запустите сервер: `python manage.py runserver`
7. Откройте браузер: http://127.0.0.1:8000/
